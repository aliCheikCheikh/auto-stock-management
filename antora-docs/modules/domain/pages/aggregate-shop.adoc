== Responsibility

`Shop` represents a physical shop. Each `StorageLocation` belongs to a `Shop`.
The initial deployment uses one shop; the model allows for multiple shops.

== Attributes

[cols="1,1,1"]
|===
| Attribute | Type | Description

| `shopId`
| `ShopId`
| Unique shop identifier.

| `name`
| `String`
| Shop name, for example "Demo Auto Parts".

| `address`
| `String`
| Physical shop address.
|===

== Invariant

A shop must have a nonempty `name`.

== Integration cost

The relationship adds one attribute, `shopId`, to `StorageLocation`, avoiding a structural migration when a second shop is added.
