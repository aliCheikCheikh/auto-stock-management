== Definition

A domain event records a significant business fact that has already occurred. Events are immutable and allow aggregates to communicate without direct coupling.

== Events

[cols="1,1,1,1"]
|===
| Event | Trigger | Publisher | Consumer / data

| `LowStockAlert`
| Global product quantity falls below `minimumGlobalThreshold`.
| Application Service after a sale or issue.
| Dashboard notifications and alerts. Data: `productId`, `productName`, `globalQuantity`, `threshold`, `occurredAt`.

| `StockReplenished`
| Global quantity rises above `minimumGlobalThreshold` after receipt.
| `ReceivingService`, via the Application Service.
| Dashboard clears the alert. Data: `productId`, `productName`, `globalQuantity`, `threshold`, `occurredAt`.

| `ShopFloorLow`
| Product quantity at a `SHOP_FLOOR` location falls below `lowStockIndicator`.
| `StorageLocation` after `decreaseStock`.
| Dashboard indicates a required transfer. Data: `productId`, `locationId`, `currentQuantity`, `lowStockIndicator`, `occurredAt`.

| `SaleCompleted`
| A sale is finalized.
| Application Service after creating the sale and movements.
| Daily revenue dashboard and reporting. Data: `saleId`, `totalAmount`, `lineItemCount`, `soldBy`, `occurredAt`.

| `StockReceived`
| A receipt is recorded.
| `ReceivingService`, via the Application Service.
| Receipt history dashboard. Data: `productId`, `totalQuantityReceived`, `locationBreakdown`, `receivedBy`, `occurredAt`.
|===

== Two alert levels

* `LowStockAlert` is critical: global quantity is below the product threshold and a supplier order is needed.
* `ShopFloorLow` is operational: the shop-floor quantity is below the location threshold and an internal transfer is needed.

These distinguish replenishment from a supplier from replenishment using existing backstock.
