== Responsibility

`User` represents a system user. The initial setup has an owner and another seller; the model supports additional users.

== Attributes

[cols="1,1,1"]
|===
| Attribute | Type | Description

| `userId`
| `UserId`
| Unique identifier.

| `name`
| `String`
| User name.

| `role`
| `UserRole`
| System role: `OWNER` or `SELLER`.
|===

== Invariant

A user must have a nonempty `name`.

== Authentication boundary

In this domain design, authentication concerns such as passwords and sessions belong to the infrastructure authentication adapter.
The domain user identifies who recorded a sale or stock movement.
