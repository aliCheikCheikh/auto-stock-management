== Responsibility

`Category` classifies catalog products, such as filters, oils and engine parts. Each product belongs to exactly one category.
Although simple, it has its own identity and can evolve independently.

== Attributes

[cols="1,1,1"]
|===
| Attribute | Type | Description

| `categoryId`
| `CategoryId`
| Unique identifier.

| `name`
| `String`
| Category name, unique across the system.
|===

== Invariants

[cols="1,1"]
|===
| Invariant | Description

| Nonempty `name`
| A category must have a name.

| Unique `name`
| The repository checks that no two categories share a name.
|===

== Possible extensions

Descriptions, images or subcategories can be added without changing how `Product` references the category through `CategoryId`.
