== Context and scenario

A customer requests four filters. There are three on the shop floor and seven in backstock.
The seller records the sale; the system allocates stock across locations.

== Sequence diagram

[plantuml]
----
@startuml
!theme plain
skinparam backgroundColor transparent

actor Seller as V
participant "SellProductUseCase" as AS
participant "ProductRepository" as PR
participant "StockAllocation\nService" as SAS
participant "Sale" as SA
participant "SaleRepository" as SR
participant "StorageLocation\n(Shop floor)" as SLM
participant "StorageLocation\n(Backstock)" as SLR
participant "StockMovement\nRepository" as SMR
participant "EventPublisher" as EP

V -> AS : sell(SellProductCommand)
activate AS

== Phase 1: Product lookup ==

AS -> PR : findById(productId)
PR --> AS : Product

== Phase 2 : Allocation ==

AS -> SAS : allocate(productId, 4, shopId)
activate SAS
SAS -> SAS : loads StorageLocation instances\n(SHOP_FLOOR first)
SAS --> AS : [(shopFloor,3), (backstock,1)]
deactivate SAS

== Phase 3: Create and persist the sale ==

AS -> SA : Sale.create(sellerId, [lineRequest])
SA -> SA : lineTotal = 4 × unitPrice\ntotalAmount = sum(lineTotals)
SA --> AS : sale (with saleId)
AS -> SR : save(sale)

== Phase 4: Execute movements ==

loop for each AllocationResult
  AS -> SLM : decreaseStock(productId, qty)
  SLM -> SLM : StockLevel -= qty\n(emits ShopFloorLow if threshold crossed)
  AS -> SLM : pullEvents()
  SLM --> AS : events
  AS -> SLM : save(location)

  AS -> AS : StockMovement.createExit(\n  productId, locId, qty, sellerId, saleId)
  AS -> SMR : save(movement)
end

== Phase 5: Global events ==

AS -> AS : globalStock = sum(locations)
alt globalStock < minimumGlobalThreshold
  AS -> AS : append LowStockAlert
end
AS -> AS : append SaleCompleted

AS -> EP : publish(events)

AS --> V : void (Sale persisted,\nmovements created, events published)
deactivate AS

@enduml
----

== Location traceability

Two movements record where units came from: three from the shop floor and one from backstock.
A single "four filters sold" record would lose location-level traceability and prevent reconstructing location quantities from movements.

== Created objects

[cols="1,1"]
|===
| Object | Values

| Sale
| `soldBy`: seller; `occurredAt`: now; `totalAmount`: 4 × unit price.

| SaleLineItem
| `productId`: oil filter; `quantity`: 4; `unitPrice`: price at sale time; `lineTotal`: 4 × unitPrice.

| StockMovement 1
| `type`: `EXIT`; source: shop floor; destination: `null`; quantity: 3; `saleId`: sale reference.

| StockMovement 2
| `type`: `EXIT`; source: backstock; destination: `null`; quantity: 1; `saleId`: sale reference.
|===

== Events

* `SaleCompleted`: always emitted.
* `LowStockAlert`: emitted if global stock < `minimumGlobalThreshold`.
* `ShopFloorLow`: emitted if shop-floor stock < `lowStockIndicator`; the shop floor reaches zero in this example.
