== Responsibility

`StorageLocation` represents a physical shop-floor or backstock location. It owns the quantity of each product stored there and protects the invariant that stock cannot be negative.

== Attributes

[cols="1,1,1"]
|===
| Attribute | Type | Description

| `locationId`
| `LocationId`
| Unique location identifier.

| `shopId`
| `ShopId`
| Reference to the owning shop, supporting multiple shops.

| `type`
| `LocationType`
| `SHOP_FLOOR` (sales area) or `BACKSTOCK` (rear storage).

| `label`
| `String`
| Readable label, for example "Main shop floor" or "Backstock".

| `lowStockIndicator`
| `int`
| Threshold below which a shop-floor location needs replenishment from backstock. Applies only to `SHOP_FLOOR`.

| `stockLevels`
| `Map<ProductId, StockLevel>`
| Stock levels by product at this location.
|===

== Internal StockLevel value object

`StockLevel` lives inside `StorageLocation`. It has no independent identity; the `(locationId, productId)` pair identifies a level.
It is immutable: each change returns a new instance.

[cols="1,1,1"]
|===
| Attribute | Type | Description

| `productId`
| `ProductId`
| Reference to the product.

| `quantity`
| `int`
| Available quantity of that product at this location, always ≥ 0.
|===

== Invariants

[cols="1,1"]
|===
| Invariant | Description

| Quantity ≥ 0
| `decreaseStock` throws `InsufficientStockException` if the resulting quantity would be negative.

| Nonempty `label`
| A location must have a label.

| `lowStockIndicator` ≥ 0
| The indicator cannot be negative.
|===

== Behavior

* `increaseStock(productId, quantity)` adds to the product's level, creating it if absent. Used for receipts (`ENTRY`) and incoming transfers.
* `decreaseStock(productId, quantity)` removes units and throws `InsufficientStockException` if the result would be negative. Used for sales (`EXIT`) and outgoing transfers.
* `getStockLevel(productId)` returns the available quantity, or zero when no level exists.
* `hasEnoughStock(productId, required)` checks whether at least `required` units are available. `StockAllocationService` uses this during allocation.
* `isShopFloorLow(productId)` returns `true` when quantity is below `lowStockIndicator` and the location type is `SHOP_FLOOR`. It signals a need for internal replenishment, rather than a critical global-stock alert.

== Why stock belongs to a location

A quantity describes a physical location: "three filters on the shop floor".
Concurrent sales must protect that location's stock. Separating levels and movements from `Product` also keeps the product aggregate small.
